# Версия 0.1.5 — подготовка размещения и iPhone

Эта версия сохраняет заметки, календарь, пометки и подсветку из 0.1.4. Добавлены настройка бесплатного Render + Neon, перенос локальной базы, помощь по установке на iPhone и обработка сна бесплатного сервера.

Пошаговое размещение: **DEPLOY_FREE_IPHONE.md**.

Для локального обновления:

1. Остановите сервер и сохраните резервную копию проекта с `.env` и `vmeste.db`.
2. Из нового архива скопируйте папки **app**, **static**, **data** в текущий проект с заменой. Для размещения также нужны **Dockerfile**, **render.yaml** и **.dockerignore**.
3. Сохраните свои `.env`, `vmeste.db` и `.venv`. Схема базы не менялась; новые аккаунты не нужны.
4. Запустите:

```powershell
.\.venv\Scripts\python.exe -m app
```

5. Откройте http://localhost:8000 и нажмите Ctrl+F5.

На локальном компьютере не включайте `APP_ENV=production`: серверный режим требует постоянную PostgreSQL-базу и HTTPS-настройки. Файл `render.yaml` включает их только на размещённом сервере.

Обновление файлов само по себе не создаёт общую ссылку. Сначала нужны аккаунты Render/Neon, перенос базы и публикация сервера по инструкции. После этого ваш компьютер можно выключать — оба iPhone будут обращаться к серверу.
