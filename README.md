# Вместе ♡ — версия 0.1.5

Совместная PWA для МАИ **М3О-237БВ-25** и МГСУ **ИПГС спец 2-64, подгруппа 1**. Исходный проект использует Python/FastAPI, SQLAlchemy и SQLite. Переход на Django не выполнялся.

Обновление работающего проекта: [UPDATE_WINDOWS.md](UPDATE_WINDOWS.md). Проверки и ограничения: [VERIFICATION.md](VERIFICATION.md).

## Размещение и iPhone в версии 0.1.5

Подготовлены бесплатное размещение Render + Neon, перенос существующих аккаунтов и заметок, постоянное хранение базы и инструкция установки на два iPhone. Пошаговый путь — в [DEPLOY_FREE_IPHONE.md](DEPLOY_FREE_IPHONE.md). Общая ссылка появится только после подключения аккаунтов и успешного размещения; сейчас это подготовленный пакет, не опубликованное приложение.

## Возможности версии 0.1.4

Общие заметки к каждой паре с сохранением на сервере; номер и чётность учебной недели по подтверждённому календарю МГСУ; подсветка текущей пары без приглушения прошедших; календарь с переходом к дате, сегодняшнему, завтрашнему и ближайшему учебному дню. Счётчика оставшихся минут нет; идея записана в FUTURE_IDEAS.md.

Для обновления нужно заменить app, static и data, сохранив свою базу и .env. Подробности — в UPDATE_WINDOWS.md. Схема базы не менялась: заметки используют существующий слой пользовательских изменений.

Пары отмечены пометками ПЗ, ЛК и ЛАБА. Тип можно выбрать в редакторе. При первом открытии в пустой выходной выбирается ближайший загруженный понедельник; ручной выбор выходного не сбрасывается при обновлении. Текущий порядок обновления версии 0.1.4 указан в UPDATE_WINDOWS.md.

## Что изменилось

МГСУ больше не ограничен публичной неделей Raspika. По умолчанию приложение скачивает PDF специалитета второго курса с официального сайта МГСУ и разворачивает семестровую сетку в конкретные даты. Для приложенного осеннего расписания 2026–2027 верхняя половина пары соответствует нечётной учебной неделе, нижняя — чётной. Неразделённая ячейка действует каждую неделю. Дополнительно учитываются первая подгруппа и явные условия по номерам недель.

Проверено живой загрузкой 7 ноября 2026 года: **16 занятий на 9–15 ноября** и **93 занятия с 9 ноября по 20 декабря**. 9–15 ноября — 11-я нечётная учебная неделя. В понедельник 11:30 — строительные материалы; на следующей чётной неделе в то же время — КОП «Цифровое моделирование».

Это базовая семестровая сетка. Разовые отмены, праздники, переносы и дополнительные занятия, отсутствующие в PDF, из неё не выводятся автоматически. Источник и доступный период видны в настройках; неподтверждённые даты не считаются свободными.

## Запуск на Windows

Для обновления используйте отдельную инструкцию выше. Для совершенно новой установки:

~~~powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
~~~

В новом .env задайте SECRET_KEY (случайная длинная строка). Существующий .env при обновлении сохраняйте.

~~~powershell
.\.venv\Scripts\python.exe -m app
~~~

Откройте http://localhost:8000. При обновлении войдите прежним аккаунтом. Для новой базы первый аккаунт создаёт пару, второй присоединяется по приглашению.

## Источники МГСУ

Режим по умолчанию — MGSU_SOURCE=auto. В старом .env эту строку можно не добавлять: значение auto используется автоматически.

1. Официальный PDF: https://mgsu.ru/student/Raspisanie_zanyatii_i_ekzamenov/fayly-raspisaniya-dlya-skachivaniya/ — приложение находит ссылку «ИПГС спец 2 курс», проверяет заголовок группы и семестр, геометрию ячеек и учебные недели.
2. Если загрузка/разбор не удался, используется включённый в data/ исходный PDF от 07.11.2026 с проверкой SHA-256. Он явно отмечается как сохранённая базовая сетка; свежая загрузка с сайта не имитируется. По сохранённой копии общие свободные окна не подтверждаются.
3. Если ни один PDF прочитать не удалось, доступен резервный гостевой интерфейс https://raspisanie-mgsu.ru/ — выбран именно специалитет ipgs-s-2-64, а не бакалавриат ipgs-2-64. Загружаются конкретные дни максимум трёх недель; отсутствие ответа одного дня прерывает замену данных.
4. Последний резерв — Raspika API при заполненном RASPIKA_API_KEY, иначе её публичная неделя. Только эти источники могут по-прежнему иметь ограничение одной недели.

В .env можно принудительно выбрать MGSU_SOURCE=pdf, web, raspika или raspika_public. После изменения перезапустите сервер. Для обычной работы оставьте auto. Ключ для PDF и raspisanie-mgsu.ru не нужен.

Интерфейс raspisanie-mgsu.ru публичный, но не документирован как стабильный сторонний API; в будущих версиях сайта его структура может измениться. Официальный PDF остаётся основным источником.

## Сохранность данных

Аккаунты и события хранятся в vmeste.db. Переменная DATABASE_URL может задавать другую базу. Ручные правки отделены от импортированных полей. При смене источника однозначно совпавшей паре переносятся ручные исправления; неоднозначные исправления остаются с отметкой конфликта. Ошибочный или пустой ответ не удаляет прежние занятия.

Схема базы не менялась. Импорт МАИ и его парсер сохранены. Проверка источников выполняется раз в сутки, по кнопке и при открытии устаревшего расписания. Изменения между аккаунтами передаются через WebSocket с резервным опросом. PWA хранит копию для просмотра без сети; без связи изменения не отправляются.

## Доступ с телефонов

Для общей ссылки нужен сервер с HTTPS и постоянной базой. Адрес localhost работает только на компьютере, где запущен проект. Подготовка размещения описана в DEPLOY_FREE_IPHONE.md. Фактическая публикация и установка на реальных телефонах пока не выполнены; push-уведомления не включены.
